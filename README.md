# DompetKu - Catatan Keuangan Pribadi

Aplikasi pencatatan keuangan pribadi instan, ringan, mobile-first, dan offline-ready dengan Progressive Web App (PWA).

## Fitur Utama
- **Pencatatan Cepat & Instan:** Mode Pengeluaran dan Pemasukan dengan chip nominal cepat.
- **Sisa Saldo Kantong Dinamis:** Pengelolaan multi-dompet (Cash, Bank, ShopeePay, GoPay, dan dompet kustom).
- **Riwayat Transaksi Harian:** Navigasi tanggal per hari yang ramah jempol dengan ringkasan harian.
- **Tema Espresso & Soft Almond:** Desain elegan, bersih, dan kontras tinggi untuk kenyamanan membaca nominal uang.
- **PWA Full-Screen Standalone:** Bisa di-install / Add to Home Screen di Android & iOS tanpa bilah browser.
